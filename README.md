# אתר אישי - יעקב לח | מתרגם שירה

אתר אינטרנט אישי בעברית (RTL) עבור המתרגם **יעקב לח**, בהשראת הקו העיצובי והטיפוגרפי של אתרי ספרות מובילים (כגון `eshkol-nevo.com`).

---

## תכונות מרכזיות
- **אסתטיקה ספרותית מינימליסטית:** פלטת צבעים חמה בהשראת דפי ספר ודיו עמוק (גווני שמנת, פחם ובורדו).
- **טיפוגרפיה עברית קלאסית:** שילוב גופני Google Fonts: *Frank Ruhl Libre* (לכותרות ושירה) ו-*Assistant* (לטקסט רץ וניווט).
- **ספרי תרגום שיצאו לאור:** מדף ספרים מפורט הכולל:
  - יוסיף ברודסקי, *הסטנצות החדשות לאוגוסטה* (הוצאת הקיבוץ המאוחד, 2017)
  - אוסיפ מנדלשטם, *שירי 1934. השיחה על דנטה* (הוצאת חבר לעט, 2015)
  - ילנה שוורץ, *אפרודיטה עוזבת בליל שבת* (הוצאת קשב לשירה, 2010)
  - שיר השירים, *תרגום מפורש לרוסית* (הוצאת Филобиблон, ירושלים, 2003)
- **טעימות קריאה ושירה:** הצגת תרגומים נבחרים עם אפשרות להצגת טקסט המקור (רוסית, אוקראינית, אנגלית) זה לצד זה.
- **תחנות חיים וביוגרפיה:** מקייב (1937) דרך המכון לחקר הנגב ומפעלי ים המלח, לימודי השירה באוניברסיטת בן-גוריון (אצל עמוס עוז, אורי ברנשטיין וענת ויסמן) ועד מפעלי התרגום.
- **טופס והזמנת הרצאות:** עמוד יצירת קשר להזמנת הרצאות ומפגשי שירה.

---

## הרצת הפרויקט

### 1. התקנת תלויות (חד-פעמי)
```bash
npm install
```

### 2. הפעלת שרת פיתוח מקומי
```bash
npm run dev
```
האתר ייפתח בכתובת המקומית: `http://localhost:4321`

### 3. בניית אתר סטטי להפצה (Production)
```bash
npm run build
```
הקבצים המוכנים ייווצרו בתיקיית `dist/`. ניתן להעלותם בקלות לכל שרת אחסון כגון GitHub Pages, Vercel, Netlify או שרת פרטי.
